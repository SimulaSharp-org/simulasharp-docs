# SimulaSharp — Framework Design

> **This standalone file has been superseded by the documentation site.** This `docs/` folder is now a
> Vite + React documentation app — the definitive guide to designing simulators with SimulaSharp, plus the
> generated API reference. Run it with `./serve.ps1` (see [README.md](./README.md)).

The whole design — the authoring model, associations, the YAML assembly, observability, the lifecycle, and packing/
hosting — is covered, current and diagram-rich, in the site:

- **Get oriented** — the introduction, the big picture, and the authoring model (Models · Services · Assemblies).
- **Concepts** — a deep chapter per idea (time, actors, scheduling, coroutines, models, associations, services,
  observability, configuration, the assembly, the lifecycle, packing & hosting).
- **Designing a simulator** — topologies, interaction patterns, model-vs-service, observability design, determinism,
  and the pitfalls to avoid.
- **Scenarios** — worked end-to-end builds, up to a multi-subsystem satellite topology.
- **Reference** — the attributes, the assembly YAML schema + diagnostics, a glossary, and the roadmap.
