# Glossary

The vocabulary of SimulaSharp, alphabetical. Each entry links to the chapter that covers it in depth.

| Term | Definition |
|---|---|
| **actor** | The concurrency unit: an independent scheduling domain with its own thread and no shared state. In SimulaSharp an actor is a **SimSite**. See [SimSites & actors](#/guide/simsites-and-actors). |
| **assembly** | The YAML file that names the sites, services, and model tree and wires them together; the generator turns it into the `<Name>Simulator`. See [the assembly](#/guide/the-assembly) and the [YAML reference](#/guide/assembly-yaml-reference). |
| **caller-site dispatch** | The generated `<Interface>Ref` wrapper's behaviour: it captures the caller's and the target's schedulers at construction; a call from the same site runs directly (inline, lock-free); a cross-site call is marshalled onto the target's thread. See [associations](#/guide/associations). |
| **collectible ALC** | A collectible `AssemblyLoadContext` — the .NET mechanism the host uses to load a packed simulator and later **unload/reload** it without restarting. See [packing & hosting](#/guide/packing-and-hosting). |
| **`Container<T>`** | The read-only accessor for **ownership** (containment): a parent's list of owned children of type `T`, declared with `[Contains<T>("Name")]` and filled from the YAML `Models` block. See [models & containment](#/guide/models-and-containment). |
| **containment** | The ownership relation between a parent model and the children it owns; the whole subtree shares the parent's site. See [models & containment](#/guide/models-and-containment). |
| **coroutine** | A model's long-running behaviour written as an `IEnumerator<SimYield>` that `yield`s to advance simulated time — SIMULA's "process" abstraction. See [coroutines](#/guide/coroutines). |
| **dispatcher** | The marshal-only capability of a site, `IDispatcher`: `Post` (fire-and-forget) and `InjectAsync`/`InjectVoidAsync` (awaitable) run work on that site's thread. A **scheduler** (`IScheduler`) adds sim-time scheduling on top. See [sites & dispatch](#/guide/sites-and-dispatch). |
| **error channel** | Each site's catch-and-log path: a throw from posted work or a scheduled entry is logged at *Error* on the site's logger and that work is dropped; the site keeps running. See [SimSites & actors](#/guide/simsites-and-actors). |
| **event queue** | A SimSite's per-site queue of due work, drained whenever the site wakes; tested synchronously via `ProcessDue(nowUs)`. See [event queue & scheduling](#/guide/event-queue-and-scheduling). |
| **global event** | A scheduler-less, ownerless, multi-producer pub/sub channel (`SimEvent` / `SimEvent<T>`), declared in the YAML `Events:` block. Any model or service may subscribe (an `[EventHandler]` method) or trigger (an `[EventReference]` member); each handler runs on its subscriber's own dispatcher. See [global events](#/guide/events). |
| **horizon** | The single 64-bit number the clock publishes: elapsed simulation time in microseconds. One writer (the clock thread), many readers (the sites). See [time & the clock](#/guide/time-and-clock). |
| **hosting** | Loading a packed simulator into a collectible context and running/observing/reloading it — the **Hosting** library, ultimately the MMI. See [packing & hosting](#/guide/packing-and-hosting). |
| **knob** | The unit of observation and control: a named readable/settable value or a trigger, marked with a `[*Knob]` attribute and streamed to a UI. See [observability](#/guide/observability). |
| **lifecycle states** | The strict progression `Initialized → Configured → Running` (the constructor assembles, landing in `Initialized`); `Stop()` freezes without leaving `Running`; single-use (no reset). See [simulator lifecycle](#/guide/simulator-lifecycle). |
| **loosely coupled service** | A clock-ungated service (`LooselyCoupledServiceBase`) for external I/O: a dispatcher thread runs the work marshalled to it, and `OnRunStarted`/`OnRunStopped` fire inline on the clock thread. See [services](#/guide/services). |
| **marshalling** | Handing work across a site boundary: the caller drops a message into the target site's lock-free inbox, which runs it on *its* thread. See [SimSites & actors](#/guide/simsites-and-actors). |
| **mission epoch** | The fixed absolute instant mission time counts from — the assembly's `MissionStart`, default the Unix epoch. See [time & the clock](#/guide/time-and-clock). |
| **mission time** | Absolute mission instant of the simulation, read as `MissionNowUs`. By default `mission epoch + horizon`; a **mission-time provider** can re-source it. See [time & the clock](#/guide/time-and-clock). |
| **mission-time provider** | An `IMissionTimeProvider` installed via `IClock.SetMissionTimeProvider` that supplies mission time in place of the default (epoch + horizon) — e.g. an FES clock fast-forwarded between ground-station passes. See [time & the clock](#/guide/time-and-clock). |
| **model** | A component you author (a `partial` class deriving `ModelBase`) with state and behaviour; the node type in the tree. See [models & containment](#/guide/models-and-containment) and [model vs service](#/guide/model-vs-service). |
| **`<Name>Simulator`** | The generated `SimulatorBase` subclass (from `Simulator.Name`) that constructs and wires everything; an `ISimulator`. See [simulator lifecycle](#/guide/simulator-lifecycle). |
| **pack (`.nupkg`)** | A finished simulator packaged via `dotnet pack`, made self-contained (private deps + `deps.json`) for a host to load. See [packing & hosting](#/guide/packing-and-hosting). |
| **parameter** | A build-time tunable: a value-type member marked `[Parameter(default)]`, filled from the instance's YAML `Config:` block or its default during assembly, read with `GetParams()` and overridable with `SetParam(...)` until `Configure()` runs. See [parameters](#/guide/configuration). |
| **plottable** | The unit of plot telemetry: a named numeric sample the host sweeps at one mission-time stamp per sweep. Marked `[Plottable]`. See [observability](#/guide/observability). |
| **reference** | A non-owning link from one model to another (possibly on another site). See [associations](#/guide/associations). |
| **`[Reference<T>]`** | The decorator for an **intra-site** non-owning link; the generator emits a read-only `IReadOnlyList<T>` of the same-site target instances (direct, no `Ref`), filled from the YAML `Refs` block. See [associations](#/guide/associations). |
| **`[CrossReference<T>]`** | The decorator for a **possibly cross-site** non-owning link (`T` must be an interface, else `SIM018`); the generator emits a read-only `IReference<TRef>` (e.g. `IReference<IPumpRef>`) of guarded `<Interface>Ref`s that capture both schedulers, filled from the YAML `CRefs` block. Members route by tier: `[Triggerable]` (notify), `[VolatileAccess]` (gauge), default (ask). See [associations](#/guide/associations). |
| **service** | A shared capability (a `partial` class deriving `ServiceBase` or `LooselyCoupledServiceBase`) with its own site, exposing generated `[ServiceEvent]` pub/sub and `[ServiceRequest]` entry points; reached by models and other services through `[ServiceRef]` members; not part of the model tree. See [services](#/guide/services). |
| **sim time** | Elapsed simulation time in microseconds — the horizon, read as `SimNowUs`; starts at 0. See [time & the clock](#/guide/time-and-clock). |
| **SimClock** | The single hard-real-time clock: one writer thread advancing the horizon at 1:1 with wall time and waking each parked site when its next event is due; `Start`/`Pause`/`RunFor`, no reset. See [time & the clock](#/guide/time-and-clock). |
| **SimSite** | An independent scheduling domain — one thread, one event queue — that runs a subtree of models lock-free and parks at 0% CPU while idle. Parallelism comes from having several. See [SimSites & actors](#/guide/simsites-and-actors). |
| **SimYield** | The value a coroutine yields to schedule its next resumption (e.g. delay a span). See [coroutines](#/guide/coroutines). |
| **`<Interface>Ref`** | The guarded wrapper the generator emits once per interface used as a `[CrossReference<I>]` target. It applies caller-site dispatch and routes members by tier: `[Triggerable]` fire-and-forget, `[VolatileAccess]` direct read, default async request/response. See [associations](#/guide/associations). |
