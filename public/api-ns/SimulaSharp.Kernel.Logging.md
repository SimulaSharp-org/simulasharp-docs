Structured logging. A component's [`ILogger`](#/api/type/SimulaSharp.Kernel.Logging.ILogger) (`LogError` / `LogWarning` / `LogEvent` / `LogInformation` / `LogDebug` / `LogTrace(depth, …)`) stamps each message with three timestamps (sim, mission, wall), an issuer (the component's full dotted path), a [`LogLevel`](#/api/type/SimulaSharp.Kernel.Logging.LogLevel) (`Error` … `Trace6`, three-letter codes via `ToCode()`), and the call site, producing a [`LogEntry`](#/api/type/SimulaSharp.Kernel.Logging.LogEntry) that fans out through a [`LogRouter`](#/api/type/SimulaSharp.Kernel.Logging.LogRouter) to every [`ILogSink`](#/api/type/SimulaSharp.Kernel.Logging.ILogSink) registered with `ISimulator.RegisterLogSink`.
