The runtime core: the clock, the scheduling domains, and the simulator base.

- [`SimClock`](#/api/type/SimulaSharp.Kernel.Services.SimClock) / [`IClock`](#/api/type/SimulaSharp.Kernel.Services.IClock) — the hard-real-time clock that publishes the horizon (control vs read-only view); [`IMissionTimeProvider`](#/api/type/SimulaSharp.Kernel.Services.IMissionTimeProvider) re-points mission time. See [Time & the clock](#/guide/time-and-clock).
- [`SimSite`](#/api/type/SimulaSharp.Kernel.Services.SimSite) — one thread + one [`EventQueue`](#/api/type/SimulaSharp.Kernel.Services.EventQueue) per scheduling domain, seen through capability interfaces: [`IDispatcher`](#/api/type/SimulaSharp.Kernel.Services.IDispatcher) (marshal) / [`IScheduler`](#/api/type/SimulaSharp.Kernel.Services.IScheduler) (sim time) / [`ISite`](#/api/type/SimulaSharp.Kernel.Services.ISite) (lifecycle) / [`IDispatcherSite`](#/api/type/SimulaSharp.Kernel.Services.IDispatcherSite). [`LooselyCoupledSite`](#/api/type/SimulaSharp.Kernel.Services.LooselyCoupledSite) is the clock-ungated variant. See [SimSites & the actor model](#/guide/simsites-and-actors), [Sites & dispatch](#/guide/sites-and-dispatch) and [the event queue](#/guide/event-queue-and-scheduling).
- [`ISimulator`](#/api/type/SimulaSharp.Kernel.Services.ISimulator) / [`SimulatorBase`](#/api/type/SimulaSharp.Kernel.Services.SimulatorBase) / [`SimulatorState`](#/api/type/SimulaSharp.Kernel.Services.SimulatorState) — the control endpoint the generated `<Name>Simulator` extends. See [the lifecycle](#/guide/simulator-lifecycle).
- [`ServiceEventChannel`](#/api/type/SimulaSharp.Kernel.Services.ServiceEventChannel) — the backing for a `[ServiceEvent]`. See [Services](#/guide/services).
