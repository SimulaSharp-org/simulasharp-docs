The plot-telemetry channel. A [`Plottable`](#/api/type/SimulaSharp.Kernel.Plotting.Plottable) is a named numeric sample on a model instance; the simulator collects them and a plot consumer sweeps them in one mission-time-stamped pass.

See [Observability](#/guide/observability) and [`[Plottable]`](#/guide/attribute-reference).
